One-line roast for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty ($5 in USDC). The entry is a single 96-character line about wireless earbuds that keep dying mid-call:

> "My earbuds die mid-sentence so often I now say goodbye at the start of every call, just in case."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes `entry.txt` (UTF-8, one line, 96 characters, no trailing newline) into the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default), then reads it back and verifies it matches the roast exactly. Standard library only, deterministic — two runs produce byte-identical output, which you can check with `diff` or `sha256sum`.

## How the line was picked

Eight candidate roasts were played off against each other in a single-elimination tournament, judged pairwise against the bounty brief (one line, actually funny, fresh angle, neatly worded, one person's specific gripe with a concrete detail). The champion then faced a tighter rewording of itself, which won — the earbuds line above. It wins on the sting of recognition: anyone whose earbuds have died mid-sentence has already started saying goodbye early.
